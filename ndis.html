NDIS Construction

Home modifications and SDA builds for NDIS participants, built to the OT's report and the standards that apply.

How we go about it

The person first

We start from how the participant actually moves around the home and what the OT has recommended, then work out what the building needs.

Built to the standard

SDA Design Standard, the NCC accessibility provisions and the relevant Australian Standards, so the work passes the first inspection.

Everyone kept in the loop

The participant, the family, the support coordinator and the plan manager all know what's happening and when we'll be there.

What we build

  • Bathrooms: roll-in showers, grab rails, hobless floors and the waterproofing under them
  • Ramps, wider doorways and level thresholds for a wheelchair
  • Kitchens set up for someone working from a chair
  • Ceiling hoist tracks, with the framing to carry them
  • SDA new builds and conversions
  • Small modifications as well as whole builds

Quotes that fit the funding

Capital Supports funding needs the quote set out a certain way. We write it so the plan manager and the NDIA can approve it without sending it back.

We work with OTs, support coordinators, providers and directly with participants and their families.
